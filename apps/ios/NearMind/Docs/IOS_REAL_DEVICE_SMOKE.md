# NearMind iOS Real Device Smoke

## A. Setup

1. Push latest backend and app commits.
2. Open `apps/ios/NearMind/NearMind.xcodeproj` in Xcode.
3. Select a physical iPhone.
4. Set the signing team for the NearMind target.
5. Build and run the app.
6. Open Settings in NearMind.
7. Paste a test JWT generated by the backend.
8. Save the token to Keychain.
9. Connect to reliable Wi-Fi.
10. Optionally use earbuds for private TTS playback.

## B. Conversation Agent Test

1. Open Live Assist.
2. Select `conversation_agent`.
3. Enter situation:

```text
Bank loan meeting preparation.
```

4. Check consent.
5. Tap Start Voice Session.
6. Grant microphone permission if prompted.
7. Say:

```text
What should I ask before this bank loan meeting?
```

8. Expect ASR final text.
9. Expect assistant text.
10. Expect native iOS TTS if unmuted and the gateway emits a TTS instruction.
11. Tap Stop save=false.
12. Confirm the microphone stops.

## C. Whisper Copilot Test

1. Select `whisper_copilot`.
2. Check consent.
3. Tap Start Voice Session.
4. Say:

```text
The APR is 9.4 percent and there is also an arrangement fee.
```

5. Expect ASR final text.
6. Expect a short voice cue.
7. Expect native iOS TTS to speak the short cue if unmuted.
8. Tap Simulate Barge-In.
9. Confirm TTS stops.
10. Tap Stop save=false.
11. Confirm the microphone stops and the session is discarded.

## D. Safety Tests

1. Deny microphone permission and confirm Start Voice Session fails clearly.
2. Disconnect during an active session and confirm mic/TTS stop.
3. Background the app during an active session and confirm mic/TTS stop plus `stop save=false`.
4. Toggle Mute TTS and confirm no local TTS speaks.
5. Open Debug Log and confirm no token appears.
6. Confirm raw audio frames do not appear in logs.
7. Fetch session state and latency summary if a session ID exists.
8. Tap Mark Log Privacy Verified after manually confirming token/audio log safety.
