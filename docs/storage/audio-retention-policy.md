# Audio Retention Policy

Raw audio is not stored by default.

Default saved data:

- transcript
- assistant messages
- cues
- summaries
- tasks, commitments, and follow-ups
- source-linked reports
- latency/evaluation metadata

Optional data:

- raw audio, only after explicit user opt-in
- attachments/documents, only after explicit upload or connector consent

Discarded sessions must not archive transcript or audio content.
