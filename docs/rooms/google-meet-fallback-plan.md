# Google Meet Fallback Plan

Google Meet is a fallback design only.

Nearmind Rooms owns the core investor-call UX because it gives the backend explicit control over consent, participant roles, transcript gating, and post-call workflow.

Future Google Meet support would require a separate Calendar/Meet approval milestone:

- read-only calendar connector must already be connected
- creating Meet links must go through action approval
- no automatic calendar writes
- no invite sending
- no artifact access without explicit user consent

No Google Meet space is created in Rooms v0.
