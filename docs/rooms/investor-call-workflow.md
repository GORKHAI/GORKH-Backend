# Investor Call Workflow

1. Create an outreach campaign.
2. Research and shortlist an investor.
3. Create a Nearmind Room from the investor.
4. Generate a guest link.
5. Host joins with authenticated token.
6. Guest opens the invite link and grants or denies consent.
7. Transcript ingestion is allowed only after required consent.
8. Host generates a post-call summary.
9. GORKH creates a draft-only follow-up action proposal.

No email is sent by GORKH v0. The follow-up draft remains review-only.
