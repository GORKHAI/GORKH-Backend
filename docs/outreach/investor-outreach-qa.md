# Investor Outreach QA

Investor Outreach QA reviews campaign quality before a human decides whether to use any draft outside GORKH.

## Checks

- Lead count and shortlist count
- Duplicate candidate count
- Average fit score
- Average source confidence
- Missing contact count
- Strong versus weak personalization counts
- Drafts needing review
- Compliance warning events

The QA layer does not send email. It produces review data only.
